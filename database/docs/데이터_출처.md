# 📚 데이터 출처 (Data Provenance)

> SafeWork AI DB의 각 데이터가 어디서 왔는지 정리. (담당: 강주호)

## 학습·통계 데이터

| 테이블/컬럼 | 원천 | 비고 |
|---|---|---|
| `accident_case` (64만행) | KOSHA 산업재해 데이터 | 모든 집계의 원천 (삭제 금지) |
| `workplace.construction_amount` | KOSHA 데이터 `건설공사금액` | 학습 시 `건설공사금액_enc` 로 인코딩 |
| `ml_training_data` | KOSHA 학습전처리 데이터 (발생형태·질병종류) | features JSONB에 인코딩값 |
| `ml_encoding_map` | KOSHA 인코딩 사전 (kosha_encodings) | 규모·연령·지역 등 한글값↔정수 |
| `accident_type_dist` | `accident_case` 집계 | 업종×규모×지역 재해분포 |
| `industry_benchmark` | `accident_case` 집계 | 업종 벤치마크 |
| `coldstart_baseline` | `accident_case` 집계 | 콜드스타트 위험도 기준 |

## 체크리스트

| 항목 | 원천 | 비고 |
|---|---|---|
| `checklist_item` (835) | SIF 데이터 + LLM 문항 생성 | item_code `SIF-CON/MFG-####` |
| `checklist_item.law_ref` | 문항↔조문 매핑 (임베딩+코사인유사도+LLM 판단) | `law_article.article_id` 목록 |
| `checklist_item.description` | SIF 실제 재해개요 | 근거 사례 |
